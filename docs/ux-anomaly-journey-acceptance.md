# UX acceptance criteria

- The anomaly workflow is visible as Scope, Detect, Explain, Drill, Validate, and Share.
- Laptop-sized desktop views default to a compact navigation rail.
- The top bar contains essential context only; secondary actions live in one overflow menu.
- Toolbars wrap inside their containers and charts remain within the central canvas.
- Advanced analysis scrolls inside the workspace rather than clipping controls or visualizations.
- Mobile retains the same journey with contained scrolling and bottom workspace navigation.
- Analytical calculations and evidence values remain unchanged.
