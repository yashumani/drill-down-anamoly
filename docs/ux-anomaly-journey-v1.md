# Simplified anomaly investigation journey

The application now organizes anomaly analysis into six understandable steps: Scope, Detect, Explain, Drill, Validate, and Share.

The desktop shell defaults to a compact navigation rail on laptop-sized viewports, moves secondary actions into a single overflow menu, and keeps the analytical canvas scrollable so controls and charts are not clipped. No financial calculation, anomaly score, hierarchy query, evidence contract, or presentation value is changed by this interface release.
